同一張地圖，五個規劃器各跑一次

五個 planner 在完全相同的情境（同地圖、同起訖點、同隱藏障礙、同行人設定）下，使用 MCL 定位各跑一次。重播由 repo 的 runner 以凍結設定重新執行，以 5 Hz 取樣。隨機抽樣的三個可以代表一般情況；挑選的兩個是為了展示差異而選，不代表整體成功率。

行人圓圈取自各 planner 自己的那一次模擬（外框為 planner 色），行人看到機器人幾乎停下時會讓行，所以同一情境的行人軌跡不一定完全重疊。時間軸的符號標出結束時刻：✓ 抵達、✕ 碰撞、◷ 逾時、■ 卡住。
