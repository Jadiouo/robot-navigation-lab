## Provenance

The project started from three course assignments: HW1 (A* / RRT* path planning), HW2 (path tracking for a bicycle model) and HW3 (PPO steering). The first version of this repository re-implemented those ideas from scratch (no course code, models or numbers are imported or used as evidence) as a tracking-controller comparison with ground-truth localization. That version's results and figures are kept under [`legacy/`](legacy/results/README.md) for provenance only.

The HW3-2 Proly/Unity game is not included. Its distribution rights could not be verified in this workspace, so it is neither a dependency nor demo material. All maps are generated by code.

Everything about perception under noise (LiDAR, odometry, MCL), dynamic and hidden obstacles, the local-planner contract, DWA, MPPI, the global replanning layer, the procedural generator, the frozen paired benchmark and the PPO local planner was added on the `uncertainty-nav` branch.

## Development process

This repository was developed with AI assistance: several AI coding agents (Claude) split the work (planning/trajectory, simulation/control, perception/localization, local planning, benchmark and statistics, packaging) and wrote most of the code and prose. The human owner directed the scope and the research question, set the evaluation rules (split by seed, freeze before test, pre-declared paired tests, negative results reported as such), reviewed the outputs, and decided what to keep, rerun or drop. Independent verification passes by separate agents found real problems that were then fixed or disclosed (for example the wording of what the frozen-config hash covers, the asymmetric tuning effort, and which report sections are exploratory). That is a statement about process, not a claim that every line was hand-written; correctness rests on the tests (`pytest`), the frozen artifacts and the generated reports.
